# Chrome plugin for BroCrew

[![Latest release](https://img.shields.io/github/v/release/brocrew/brocrew-plugin-chrome)](https://github.com/brocrew/brocrew-plugin-chrome/releases/latest) [![License: Apache-2.0](https://img.shields.io/badge/license-Apache--2.0-blue)](LICENSE) ![Platform: macOS](https://img.shields.io/badge/platform-macOS-lightgrey)

Let BroCrew's agents use Google Chrome with separate browser profiles to read pages, use sites and save downloads.

## Install

In BroCrew, open **Settings → Plugins → Install** and choose **Chrome**. BroCrew downloads the plugin from [this repo's Releases](https://github.com/brocrew/brocrew-plugin-chrome/releases/latest) and checks its SHA-256 checksum.

**Privacy:** Agents can see pages and downloads in the plugin's browser profiles; you control access with the switches in Settings.
